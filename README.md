## ✨ Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| **⚡ Real-time Generation** | QR code langsung muncul saat mengetik URL |
| **🎨 Kustomisasi Warna** | Pilih warna QR dan background dengan color picker |
| **🖼️ Upload Logo** | Tambahkan logo di tengah QR (format PNG, JPG, dll) |
| **📏 Atur Ukuran Logo** | Slider untuk mengatur ukuran logo (10-35%) |
| **📱 Responsive Design** | Tampilan sempurna di desktop, tablet, dan mobile |
| **⬇️ Download PNG** | Simpan QR code sebagai file PNG berkualitas tinggi |
| **✅ Validasi URL** | Peringatan otomatis jika URL tidak valid |
| **🔄 Preview Realtime** | Semua perubahan terlihat langsung tanpa reload |
| **🔄 Tombol Reset** | Kembalikan ke pengaturan default dengan sekali klik |
| **🔒 Privacy First** | 100% client-side, data tidak dikirim ke server |
